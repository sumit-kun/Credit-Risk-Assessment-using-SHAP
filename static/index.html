About the model

CrediSense scores each application with a machine learning model trained on historical loan outcomes. Given the applicant and loan details above, it estimates the probability of default and compares that estimate against a fixed decision threshold to arrive at a low-risk or high-risk read.

Predictions are informational and should not be used as the sole basis for a lending decision.
